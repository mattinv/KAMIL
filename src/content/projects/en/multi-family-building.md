## About the Project

Insulation and facade rendering of a multi-story residential building. Work was carried out using full facade scaffolding.

### Scope of Work

- Facade scaffolding installation
- Wall insulation with the ETICS system
- Facade rendering
- Sheet metal flashings and window details
- Scaffolding dismantling and cleanup
